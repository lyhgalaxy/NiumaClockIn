# 牛马打卡

适用于 **Android 8.0 及以上**的模拟定位应用。可以输入 WGS-84 经纬度、搜索中文或英文地点、在地图上选点，并收藏常用地点。本仓库仅提供安装包和使用说明，不包含应用源码。

## 安装与首次设置

1. 下载并安装上方 APK。它使用开发测试签名；如手机已有不同签名的同名应用，可能需要先卸载旧版。
2. 在手机设置中开启“开发者选项”，找到“选择模拟位置信息应用”，选择“牛马打卡”。三星手机的菜单名称和路径可能因系统版本而异。
3. 打开应用，首次启动模拟定位时授予**精确定位**权限，并确保手机系统定位服务已开启。

## 选择与使用位置

1. 在首页的“目标位置”中输入 WGS-84 纬度、经度，或点“搜索地点 / 地图选点”。
2. 搜索中文或英文地点后，点选结果；在地图上核对标记和顶部坐标。也可以直接点地图选位置，或修改顶部坐标。
3. 在地图页点顶部“确认”或底部“使用此位置”，将坐标带回首页。此时还没有开始模拟。
4. 在首页点“开始模拟”。首页状态区和通知会显示正在模拟的坐标。
5. 更换目标位置后，点“更新定位”即可切换，**不需要先停止**。只有需要结束模拟时才点“停止模拟”。

收藏地点时，在首页“目标位置”卡片中填写名称（可留空），点“收藏”。以后在“常用地点”选择该地点，点“使用此地点”填回目标位置，再点“开始模拟”或“更新定位”使其生效。收藏只保存在本机。

## 权限与网络

应用使用精确／大致定位、网络和前台定位服务相关权限；不要求电话、通讯录或文件访问权限。地图需要网络连接。搜索地点时，查询名称会发送给手机的地理编码服务及 Photon 公共搜索服务；地图数据来自 OpenFreeMap，备用地图使用 OpenStreetMap 瓦片。

Android 会将此应用提供的位置标记为**模拟位置**。其他应用可以识别并拒绝模拟位置，本应用不保证任何第三方打卡应用接受它。百度地图或高德地图显示的坐标可能不是 WGS-84，请在本应用地图上再次核对。
